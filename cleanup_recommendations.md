### 2. Consolidate Batch Analysis Scripts
Since `SPPARK_IPF_KAM_analysis.py` appears to be the most complete version:
1. Make it the primary script
2. Add command-line arguments for configuration
3. Remove the other batch_analyze_*.py variants

### 3. Fix Hardcoded Limitations
Replace hardcoded test limits with command-line arguments:


## Configuration Cleanup

### 1. Remove Permanently Disabled Features
If Method 1 rendering is never used, remove it entirely rather than keeping it disabled.

### 2. Create Configuration File
Move all configuration constants to a config file or command-line arguments:

```python
# config.py or as argparse arguments
class Config:
    DATA_DIR = "..."
    OUTPUT_DIR = "..."
    IPF_DIRECTION = 'z'
```
