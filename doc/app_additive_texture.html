app_style additive/texture command

Syntax: 

app_style additive/texture nspins dx dt nrefine
  • style = additive/texture
  • nspins = number of possible Potts model spins
  • dx = lattice spacing in meters (SI)
  • dt = simulation timestep in seconds (SI)
  • nrefine = number of post-solidification rejection-MC refinement passes per voxel

The legacy style name additive_temperature_texture is accepted as a deprecated alias for backward compatibility with existing input scripts; using it prints a warning at parse time. Switch to additive/texture when convenient.

Examples: 

app_style additive/texture 1000000 5e-6 5e-6 2

Description:

This is an on-lattice additive manufacturing (AM) application derived from app_style potts/quaternion. It simulates melting, solidification, and texture evolution driven by an externally-supplied temperature field. Crystallographic orientations are tracked on each site as unit quaternions, and grain mobility is biased by the local thermal gradient direction so that columnar / textured solidification and competitive grain growth emerge naturally.

The temperature field is provided by a modular temperature source plugin selected at runtime via the setup_temperature_source command. Three source families are currently available:

  • rosenthal : steady-state moving-frame analytical solution (point source, anisotropic point source, or surface point + line-source keyhole).
  • moser : unsteady time-domain Green's function convolution of an ellipsoidal Gaussian source moving along a path; supports a Goldak-style overlapping double-ellipsoid keyhole mode and per-emission stochastic source-width and power fluctuations.
  • hdf5_unstructured / hdf5_csr : reads time-resolved unstructured FE thermal data (e.g. Sierra / Diablo / Albany) from HDF5 files and interpolates to lattice sites.

The rosenthal and moser sources additionally consume a laser_path command (linear scan, optionally repeated) that defines the laser trajectory in world coordinates, and the moser source optionally consumes laser_fluctuations commands that attach Power Spectral Density (PSD) noise streams to the source widths and power.

For each lattice site, every timestep the application: (1) queries the active temperature source for T(x,y,z,t); (2) tags the site as molten when T >= liquidus, mushy when solidus <= T < liquidus, and solid otherwise; (3) randomizes the spin and quaternion at sites entering the molten state; (4) evolves quaternions through the mushy band using a Monte Carlo nucleation model (threshold or continuous, see nucleation_mode) and the analytical solidification-front velocity polynomial solid_front_vel; (5) applies nrefine rejection-MC smoothing passes per voxel after solidification, optionally followed by single-voxel-grain cleanup.

Application-specific commands:

The following commands are parsed by this application's input_app hook in addition to all general SPPARKS commands.

Thermal and material properties:

  • liquidus Tl : liquidus temperature in K.
  • solidus Ts : solidus temperature in K.
  • solid_front_vel N c0 c1 ... cN-1 : coefficients of the polynomial v(dT) used as the analytical solidification-front velocity in the mushy band.

Nucleation:

  • nucleation_density n0 : volumetric nucleation site density in sites per m^3.
  • critical_undercooling dTc : mean critical undercooling for heterogeneous nucleation in K.
  • undercooling_deviation sigma_T : standard deviation of the critical undercooling distribution in K.
  • mean_nuclei_volume Vn : mean grain-volume cap for newly nucleated grains in m^3.
  • nuclei_volume_deviation sigma_V : standard deviation of nucleated grain volume in m^3.
  • nucleation_mode threshold|continuous : threshold uses a hard dT-crossing trigger; continuous uses a temperature-rate-weighted Gaussian probability per timestep. Default = threshold.

Texture and misorientation:

  • texture_parameters c2 c3 : mobility model mob(theta) = 1 + c2 * cos(c3 * theta) where theta is the misorientation between the grain's 100 family and the local thermal gradient. c2 >= 0 and c3 * acos(1/sqrt(3)) <= pi are enforced for monotonicity.
  • misorientation_function max_misorient mis_thresh optionally followed by alpha : parameters of the per-event misorientation envelope; mis_thresh is supplied in degrees and converted to radians.
  • misorientation_target gradient|random : selects whether misorientation is computed against the local thermal gradient (default) or a fixed random target axis.

Temperature source plumbing:

  • setup_temperature_source type followed by source-specific args : choose and configure the temperature source plugin. Required.
  • laser_path start X0 Y0 Z0 end X1 Y1 speed V optionally followed by repeats N : defines the laser trajectory (Rosenthal / Moser sources only).
  • laser_fluctuations psd optionally followed by top|bot|both shape ... : attach PSD noise streams to the Moser source widths and power.

Temperature post-processing:

  • temperature_smooth tmin tmax sigma_xy sigma_z optionally followed by alpha guard passes diag_interval : opt-in Gaussian smoothing of the temperature array inside an in-window band, intended for the solidification region. alpha is the blend factor; guard is a soft taper outside the window so sites moving in or out of the band do not see a discontinuity.
  • nodal_smooth sigma_xy sigma_z passes alpha : nodal mesh-Laplacian smoothing of the temperature field at the source level (forwarded to sources that implement it; no-op otherwise).

Microstructure post-processing:

  • single_voxel_cleanup on|off : after a voxel exits the nrefine window, if its full 26-neighbor first shell is solidified and contains no same-spin neighbor, flip it to the energy-minimizing neighbor grain. Default off.
  • smooth_greedy_multiproposal on|off : during nrefine smoothing passes, evaluate every distinct neighbor spin and adopt the energy-minimizing one (steepest descent) instead of testing one random proposal per pass. Default off.

Voids (porosity):

  • void_density n : volumetric pore density in voids per m^3. Mutually exclusive with void_pore_fraction.
  • void_pore_fraction f : target volumetric pore fraction in [0, 1). Mutually exclusive with void_density.
  • void_size_distribution mean std min max : truncated normal distribution of pore radii in micrometers.

HDF5 source optimization:

  • temperature_optimization spatial_grid|element_cache|nodal_precompute on|off : toggle per-feature performance optimizations on the HDF5 source.
  • fast_forward_search_window seconds : look-ahead window used by the Rosenthal fast-forward predictor when scanning forward in time for the next melt event. Default 0.1 s.

Site state:

After construction this app exposes the following per-site arrays: 

iarray0    = spin (grain ID)
iarray1    = active_flag (0=inactive, 1=active layer, 2=molten,
                            3=solidified, 5=void)
darray0..3 = (q0, qx, qy, qz) unit quaternion
darray4    = mobility_out (computed each step)
darray5    = T (temperature, K)
darray6    = solid_d (refinement-pass countdown)
darray7    = G (thermal gradient magnitude at solidification)
darray8    = V (solidification rate at solidification)

Substrate vs. powder layers and the per-site initial state are set with the standard set command before the run.

Example inputs:

Representative input scripts live in two parallel directories, one per analytical source family: 

examples/rosenthal_am/in.additive.rosenthal_standard : steady-state point source
examples/rosenthal_am/in.additive.rosenthal_aniso    : anisotropic stretch
examples/rosenthal_am/in.additive.rosenthal_keyhole  : Rosenthal keyhole mode
examples/moser_am/in.additive.moser                  : single-pass Moser baseline
examples/moser_am/in.additive.moser_multiscan_fluct  : Moser standard-mode multi-pass
                                                       with PSD fluctuations
examples/moser_am/in.additive.moser_keyhole          : Moser double-ellipsoid keyhole
                                                       with independent top/bot streams

Restrictions:

This application requires app_style potts/quaternion behavior and is restricted to square cubic lattices. It can only be evolved by a rejection KMC (rKMC) algorithm; see the sweep command for more details. The create_sites command must be called before the first temperature query.

Related commands:

app_style potts/quaternion, app_style am/ellipsoid, app_style potts/am/path/gen, setup_temperature_source, laser_path, laser_fluctuations

Default:

nucleation_mode = threshold misorientation_target = gradient single_voxel_cleanup = off smooth_greedy_multiproposal = off fast_forward_search_window = 0.1 s temperature smoothing = off (until temperature_smooth is issued) void generation = off (until void_density or void_pore_fraction is issued)
