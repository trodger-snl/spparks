diag_style sinter_free_energy_pore command

diag_style sinter_free_energy command

Syntax: 

diag_style style keyword value keyword value ...
  • style = sinter_free_energy_pore or sinter_free_energy
  • see the diag_style command for additional keywords that can be appended to a diagnostic command

Examples: 

diag_style sinter_free_energy_pore
diag_style sinter_free_energy

Description:

The sinter free energy pore diagnostic computes the surface area of the pores in the powder compact simulated. The calculation is done over the 1/27th central parallelepiped in order to avoid border effects. To obtain a measure independent of the size of the simulation the value computed is normalized by dividing over the volume used. The pore free energy is printed as stats output (column FE_psite) via the stats command.

The sinter_free_energy diagnostic counts the pore surface over the whole domain, unnormalized: the number of (grain site, pore neighbor) pairs. It is printed as stats output in column InterfFE.

Restrictions:

This diagnostic can only be used for the sintering application.

Related commands:

diag_style, stats

Default: none
